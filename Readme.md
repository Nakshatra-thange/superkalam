# UPSC Interview Mock: a voice AI board

A real-time voice agent that conducts a UPSC Personality Test mock interview in English, Hindi or Hinglish. It remembers the candidate's DAF details, cross-questions based on what they actually say, and gives scored feedback from a separate evaluator model. Includes an eval suite and a progress dashboard.

Demo: [Loom link]

## How it works

```text
Mic -> LiveKit -> VAD -> Sarvam STT (saaras:v3) -> turn detector -> LLM (the board) -> Sarvam TTS (bulbul:v3) -> Speaker
                                                      |
                                    SQLite memory: DAF profile + past interviews
                                    Tools: save_profile, finish_interview
                                                      |
                              finish_interview -> separate evaluator LLM -> 6-dimension scores
```

- Questions are generated by the LLM from the candidate's saved profile and live answers. There is no fixed question bank.
- Three intensity modes: gentle, standard, tough.
- Scores: clarity, depth, balance, awareness, authenticity, composure. The weakest area is probed more in the next session.

## Design decisions

1. Started with a fixed question bank and RAG over notes. Dropped both: they made the agent a quiz engine with limited knowledge. The LLM now drives the interview.
2. Separated the interviewer from the evaluator. The interviewer used to score itself, which is unreliable. A second model scores the saved transcript.
3. Kept a cascaded STT, LLM, TTS pipeline instead of speech-to-speech for control: swappable components, transcripts for evals, and Indian-language STT/TTS comparison. [Add the realtime-model comparison here if you do it.]

## Limitations

- Small eval sample; results are indicative, not statistically strong.
- The LLM can state wrong facts; the evaluator flags only high-confidence slips.
- Knowledge may be outdated for recent current affairs; the board is told to ask rather than assert.
- The evaluator is an LLM judge and has not been validated against human UPSC evaluators.
- No authentication; local single-user storage only.

## Run it

```bash
uv sync
cp .env.example .env.local   # add LIVEKIT_*, SARVAM_API_KEY, ANTHROPIC_API_KEY
uv run python src/agent.py dev
uv run streamlit run dashboard/app.py
uv run python evals/stt_eval.py
uv run python evals/simulate.py
uv run python evals/judge_transcripts.py
```
